# 💍 MilanMatch

MilanMatch is a simple matrimonial web application built as a
full-stack project concept.

## ✨ Features

- 🔐 Login & Signup
- 👤 Create Matrimonial Profile
- 🔎 Profile Discovery
- ❤️ Profile Shortlisting
- 💕 Match Management
- 👀 Profile Details
- 📱 Responsive Design

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git & GitHub
